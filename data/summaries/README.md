# Book and chapter summaries

One JSON file per group (g01.json … g10.json). Shape:

{
  "Genesis": {
    "line": "One sentence: what this book is.",
    "more": ["3–6 short points: how the book unfolds."],
    "chapters": {
      "1": {"line": "One sentence: what happens in this chapter.", "more": ["2–4 short points."]},
      ...every chapter...
    }
  }
}
